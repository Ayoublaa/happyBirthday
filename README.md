# Pour Koki, avec tendresse ✨

Une page d’anniversaire d’Ayoub pour Kaoutar (Koki) : lettre, photos, musique « Joyeux anniversaire », jeu de constellation avec capsules, quiz personnalisé sur ses goûts, cadeau animé, illustration du ciel et frise interactive.

Le quiz connaît ses favoris : brownie, jus d’ananas, vert canard et Nadia Fadil. Quatre bonnes réponses révèlent un bracelet en or et le message du livreur pour demain.

## Ouvrir
Ouvre `index.html` dans un navigateur récent. Garde les fichiers avec les dossiers `photo` et `music`. La musique démarre après un clic. L’illustration du ciel est intégrée à la page; le lien vers les archives NASA nécessite une connexion Internet.

## Partager par WhatsApp
Publie le dossier birthday complet, avec `photo` et `music`, sur GitHub Pages, puis partage le lien.

## Personnaliser
Les prénoms, la date de naissance et la date anniversaire à utiliser se règlent dans l’objet `CONFIG` au début de `script.js`. Le contenu du quiz et les réponses sont dans `tasteQuestions`.

La frise du ciel utilise les heures UTC. Les positions zodiacales indiquées sont à midi UTC; l’heure et le lieu de naissance préciseraient la position de la Lune. Références : https://eclipse.gsfc.nasa.gov/OH/OH2004.html et https://www.selfgazer.com/sky/date/2004-10-14
Apres le quiz, les bougies s’allument et le fichier audio Perfect du dossier music se lance dans la page avant la revelation du cadeau.
